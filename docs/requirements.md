# 機能要件・ドメイン仕様

[目次へ](../README.md)

## 1. 利用者と権限

| 操作 | 未ログイン | ログイン済み | 所有者 |
|---|---|---|---|
| 公開ピン・公開計画の閲覧 | 可 | 可 | 可 |
| 下書きの閲覧 | 不可 | 他人のものは不可 | 可 |
| ピン・計画の作成 | 不可 | 可 | 可 |
| 自分のピン・計画の編集・削除 | 不可 | 他人のものは不可 | 可 |
| いいね・通報 | 不可（暫定） | 可 | 可 |
| 他人の公開ピンを計画に追加 | 不可 | 可 | 可 |

## 2. ピン

- **確定**: ピンはタイトルと座標が必須。本文（プレーンテキスト）、絵文字、画像を扱う。
- **確定**: 投稿の状態は `draft` / `published`。訪問済みかどうかとは独立した概念。
- **確定**: 下書きは作成者だけが閲覧でき、任意のタイミングで公開できる。
- **確定**: 一度公開したピンは下書きに戻せない。編集・削除は可能。
- **確定**: ピンの日時は投稿日時を意味する。作成日時・更新日時を別に記録するのは**暫定案**。
- **確定**: 画像は最大3枚、各5MB、圧縮・リサイズ・メタデータ除去。動画なし。
- **確定**: 星の数は「いいね件数」。投稿一覧は新着順といいね順。
- **確定**: 本文・本文中ハッシュタグによる検索。
- **未決定**: 文字数上限、絵文字の必須性、住所の保存要否、ハッシュタグの抽出方式、投稿のURL設計。

## 3. 旅行計画

- **確定**: 計画はタイトル、絵文字、本文、画像、およびピンと「ひとコマ」を含む項目列を持つ。
- **確定**: 計画にも `draft` / `published` がある。
- **確定**: 下書きピンを含む計画は公開不可。公開済み計画へ下書きピンを追加する操作は拒否。
- **確定**: 下書きピンを下書き計画へ追加できる。
- **確定**: 自分または他人の公開ピンを追加できる。同じピンを複数計画から参照できる。
- **確定**: 計画内のピン順はドラッグで変更できる。
- **確定**: ひとコマは移動・集合・休憩など、特定の場所に紐づかない行動や時間を登録するための項目。
- **確定**: ピンとひとコマはそれぞれ一つの時間を持つ。ピンごとの移動時間は表示・データともに廃止し、移動はひとコマで表現できる。
- **提案**: 共通の時間は任意の所要時間（分）として手入力する。集合時刻などの時刻は別項目とするかを含め未決定。
- **確定**: 計画削除では元のピンは削除しない。
- **確定**: 参照先ピンが削除された場合、計画上には「ピンが見つかりません」とゴミ箱アイコンを表示する。
- **未決定**: 公開計画を下書きに戻せるか、同じピンの重複登録可否、計画の空公開可否、ひとコマのみの計画の公開可否、ひとコマの並べ替え、時間の意味・必須性・入力形式、訪問日時・計画開始終了日の有無、他人の投稿編集時の反映。

## 4. いいね・ブックマーク・通報

- **確定**: 星は投稿に対するいいね件数。
- **暫定**: いいねはログイン必須・1ユーザー1ピン1件・再押下で解除。
- **確定**: ブックマークは初期完成の必須機能ではないが、DB拡張を想定。ピンと旅行計画の双方を参照できるようにする。
- **確定**: 通報は記録を残し、管理者が確認して手動削除する。発表時点では管理画面や自動モデレーションは不要。
- **未決定**: 通報対象がピンのみか旅行計画も含むか、いいねが計画にも付くか、通報者の認証要件。

## 5. 対象外

- アプリ内の経路案内。
- 動画アップロード。
- 限定公開・グループ限定公開。
- AI旅行計画提案（将来構想）。
- プロフィール画面（初期必須ではない）。

## 6. 完成の判断

**暫定の最小受け入れシナリオ**:
1. 非ログイン利用者が公開地図・投稿一覧・旅行計画を閲覧できる。
2. Googleログイン後に下書きピンを作り、写真を追加して公開できる。
3. 公開ピンを地図・一覧に表示し、本文検索・いいね順で閲覧できる。
4. 下書き計画を作り、ピンを並べ替え、時間を入力し、条件を満たすと公開できる。
5. 他人の公開ピンを計画に追加できる。
6. 所有者だけが編集・削除でき、退会時に所有データと画像を削除できる。
7. 通報を保存できる。

最終的な必須機能の範囲は未承認。
