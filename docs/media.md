# 画像・メディア仕様

[目次へ](../README.md) · [DB](./database.md) · [API](./api.md)

## 1. 確定要件

- ピン画像: 最大3枚。
- 画像1枚: 最大5MB。
- 画像は圧縮・リサイズする。
- EXIF等のメタデータはすべて除去する。
- SVGは受け付けない。
- 画像の追加・削除・並び替えを許可する。
- ピン削除・退会時は関連画像を削除する。
- 動画アップロードは実装しない。

## 2. ストレージ（暫定）

Cloudflare R2を画像本体の保存先候補とする。D1の `pin_images` にはオブジェクトキー・順序・メタ情報を保存する。計画画像の保存方法・枚数制限は未決定。

## 3. アップロード処理（暫定）

1. ログイン・対象ピンの所有者確認。
2. 画像枚数上限・受信サイズ・ファイル実体を検証。
3. 対応形式へデコードし、リサイズ・再エンコードしてメタデータを除去。
4. R2に保存。
5. D1に画像キー・順序を記録。
6. 失敗時は孤立ファイルを残さないよう補償削除・再試行を行う。

ブラウザ側の圧縮だけではメタデータ除去やファイル検証の保証にならない。サーバー側で再検証する。

## 4. 未決定

- 対応形式（JPEG / PNG / WebPなど）。
- 最大ピクセル数、変換後形式、画質。
- Cloudflare上での画像変換方式と利用料金。
- 直接アップロードとサーバー経由の選択。
- 画像配信URLとキャッシュ設定。
- 旅行計画の画像枚数・サイズ・編集方法。
- R2のバックアップ方針。
